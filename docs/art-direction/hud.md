# Pixel HUD reference pass

The built-in image-generation tool produced `hud-reference.png` from an actual gameplay screenshot. It is a design reference only; the application never loads this file.

The implemented HUD uses code-drawn, integer-scaled Canvas frames, an original bundled 5×7 pixel font, native accessible buttons and sliders, and generated sprite icons. The scoreboard shows team health and remaining worms; the center badge shows round and remaining turn time. Inventory slots retain the actual F1–F4 / M shortcuts (the reference's numeric shortcuts would conflict with grenade fuses). The power meter tracks charging and clears on release/cancel. Nameplates use team-colored health strips. The same frame and typography treatment covers match setup, field-kit/special-weapon trays, and result cards.

The font's original glyph definitions and build script are in `scripts/make-pixel-font.py`. Rebuild with `python scripts/make-pixel-font.py` in an environment with `fonttools` installed. The generated TTF is committed as a runtime asset; no font service or build-time Python dependency is needed to run the game.
